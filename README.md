# super_store__sales_dashboard-
Power BI Dashboard
project oblective :To develop an interactive Super Store Sales Dashboard using Power BI that provides insights into sales, profit, customer segments, shipping modes, regional performance, and sales trends, helping stakeholders analyze business performance and support data-driven decision-making
steps:Collected and imported Super Store sales dataset into Power BI.
Cleaned and transformed data for accurate analysis.
Created data model and relationships between tables.
Built interactive dashboards for sales, profit, and regional analysis.
Analyzed customer segments, payment modes, and shipping performance.
Added sales forecasting and year-over-year trend analysis.
Generated business insights to support data-driven decision-making.
insights:Technology category had the highest sales.
West region generated the most revenue.
Consumer segment contributed the highest share of sales.
Standard Class was the most used shipping mode.
action items:Focus more on high-performing categories like Technology to increase revenue.
Improve marketing and sales strategies in lower-performing regions.
Encourage faster payment methods to reduce dependency on COD.
Optimize shipping operations based on customer preferences.
